# Bundle contents

- Root Python scripts: SRI calculation, event recomputation, validation, aggregation, comparison, plotting, document building, and deliverable validation.
- `METHOD_SPEC.md`: frozen computational method.
- `README.md`: input contract and portable commands.
- `requirements.txt`: direct Python dependencies.
- `outputs/aggregated`: scenario-specific-calibration aggregate results.
- `outputs/common_reference_aggregated`: primary common-reference aggregate results.
- `outputs/calibration_comparison`: calibration-scheme comparison outputs.
- `outputs/validation`: model-output and deliverable validation reports.
- `outputs/figures/common_reference`: PNG, PDF, and SVG figure exports. TIFF duplicates are excluded to keep the bundle compact.
- `outputs/smoke`: four limited H08 smoke-test CSV files.

Raw NetCDF inputs, shapefile components, full model-event tables, temporary DOCX/PDF builds, caches, and TIFF files are not included.
